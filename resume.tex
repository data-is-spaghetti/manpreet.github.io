\section*{Projects}

\projectheader{WalletX}{Wealth-Partitioning OS}{2025}

A non-custodial financial OS that lets users architect every rupee across
purpose-built partitions: cash, equity, crypto, hard assets, under one
unified ledger. Built on a PERN + TypeScript stack chosen for ACID
correctness (Postgres NUMERIC, Decimal.js) rather than convenience. Day-0
architecture covers cash partitions, transfers, and a per-partition
encryption-key security model.

\textbf{Stack:} TypeScript, React, Fastify, PostgreSQL, Prisma, Redis, Zod

\vspace{6pt}
\projectheader{Caff\`ehop}{Coffee discovery and identity platform}{2025}

A coffee-first discovery and identity platform: sign up, verify, and build
a profile around the caf\'es you visit. Next.js 14 App Router frontend,
Express plus MongoDB backend, email and phone OTP with refresh-token
rotation. Hashed OTP storage with 10-minute TTL and httpOnly cookie sessions.

\textbf{Stack:} Next.js 14, React 18, Node.js, Express, MongoDB, JWT, Tailwind

\vspace{6pt}
\projectheader{CodeLens}{Multi-agent code review CLI}{2025}

A developer tool that runs code reviews through LLMs with a pluggable
provider backend (Ollama, Gemini, Mistral) via a clean provider abstraction.
RAG pipeline over codebase context with token-by-token SSE streaming,
multi-agent orchestration (context agent plus review agent), single-line
install with pre-push git hook. Published to npm.

\textbf{Stack:} TypeScript, Node.js, REST APIs, RAG Pipelines, SSE, npm

\vspace{6pt}
\projectheader{Stellarcast}{Real-time astronomy overlay (Chrome extension)}{2025}

A Chrome MV3 extension overlaying live astronomical data onto the browser.
Service-worker pipeline syncs open APIs every 60 seconds. Renders 8K+ data
points via instanced Three.js meshes at 60fps, using spatial hashing for
sub-millisecond lookups.

\textbf{Stack:} TypeScript, Chrome MV3, Service Workers, Three.js, WebGL
