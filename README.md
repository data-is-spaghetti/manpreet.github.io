# Manpreet Kaur — Portfolio

[Live site](https://thefireflysparkle.github.io/manpreet.github.io/)

A personal portfolio rendered as a navigable coordinate system.
Built with React, React Three Fiber, and Framer Motion.

## Stack

- React 18 · Vite
- React Three Fiber · Three.js · @react-three/drei
- Framer Motion
- LaTeX (résumé)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deployed via GitHub Pages on push to `main`. Workflow in `.github/workflows/deploy.yml`.
